How the code BARB0DBZIRA is built

BARB is the bank part: the letters of Bank of Baroda. The fifth character is always the digit 0. DBZIRA is the part that names this branch.

The MICR code 142012102 is the number printed along the bottom of this branch's cheques. 142 is the city (the same three digits that begin the PIN code 142047), 012 is the bank and 102 is the branch.
