How the code SBIN0051051 is built

SBIN is the bank part: the letters of State Bank of India. The fifth character is always the digit 0. 051051 is the part that names this branch.

The MICR code 147002074 is the number printed along the bottom of this branch's cheques. 147 is the city (the same three digits that begin the PIN code 147002), 002 is the bank and 074 is the branch.
