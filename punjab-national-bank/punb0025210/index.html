How the code PUNB0025210 is built

PUNB is the bank part: the letters of Punjab National Bank. The fifth character is always the digit 0. 025210 is the part that names this branch.

The MICR code 144024662 is the number printed along the bottom of this branch's cheques. 144 is the city (the same three digits that begin the PIN code 144527), 024 is the bank and 662 is the branch.
